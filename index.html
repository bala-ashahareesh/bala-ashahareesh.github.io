The Attention Mechanism

At the heart of modern transformers lies the scaled dot-product attention. It can be expressed as:

\[ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V \]

Where \(Q\) is the query matrix, \(K\) is the key matrix, and \(V\) is the value matrix. The \(d_k\) term is the dimension of the keys, acting as a scaling factor to prevent the dot products from growing too large.

Hardware Implications

When mapping this to an NPU, the matrix multiplication \(QK^T\) requires significant MAC (Multiply-Accumulate) throughput. For a standard block size, we might write a naive python simulation like this:

def attention(q, k, v):
    # Matmul Q * K^T
    matmul_qk = np.dot(q, k.T) 
    # Scale
    scaled_attention_logits = matmul_qk / np.sqrt(k.shape[-1])
    # Softmax
    attention_weights = tf.nn.softmax(scaled_attention_logits, axis=-1)
    # Matmul with V
    output = np.dot(attention_weights, v)
    return output
